Naked Nuras Loves Rave

AOA EP is a four-track plate from the 010819 master session, released as a Friday drop on iama.cc, as MAGMA, and as a public git for @nlsrecords.

MAGMA is the neuro-linguistic visual interpreter: type a sentence; the four axioms grow it as magma. Dual machines — Noise protocol vs Improved Noise — ride MORE'S LOW and TRACK FOR. GETAFIX is MixKey. TRYTO is surplus circulation.

Naked Nuras Loves Rave. NLS Records. Hong Kong. Visual music. The git is the distribution: clone, play, keep.
