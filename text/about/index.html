About NLS RECORDS

NLS RECORDS — nonlinear music label. Visual and music as an art of realization.

NLS (Nonlinear / nonlineari) is a music and visual systems label. Sound and image are treated as one practice.

Original site nlsrecordings.com is offline. This rebuild lives at https://iama.cc on GitHub Pages.

Text edition: no CSS, no JavaScript, no images. Built with Node alone: node build.js

Graphical site: https://iama.cc/
